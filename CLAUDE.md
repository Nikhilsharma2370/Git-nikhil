# Nikhil ki Learning Journal

Ye repo Nikhil ka learning log hai. Rule simple hai: **jo jo Nikhil seekhta hai, wo yahan save hota hai, aur Claude bhi wahi seekhta hai.**

## Claude ke liye instructions

1. **Har naye session ki shuruaat me** `learnings/README.md` padho, taaki pichli saari learnings yaad rahein.
2. Jab Nikhil koi naya breakdown, screenshot, tutorial ya technique share kare:
   - Sahi topic folder me ek nayi note banao (`learnings/<topic>/NN-short-name.md`), numbering aage badhao.
   - Reference image ho to `learnings/<topic>/assets/` me same naam se save karo.
   - Note me likho: kya dikh raha hai, kyun kaam karta hai, aur step-by-step kaise banana hai (exact settings ke saath).
   - `learnings/README.md` ke index me nayi entry jodo.
   - Commit karke push karo.
3. Jab Nikhil koi design, video ya edit ka kaam bole, pehle check karo ki koi purani learning lagu hoti hai ya nahi, aur use apply karo.
4. **Remotion / short-form video editing ka koi bhi kaam ho** (captions, hook, animation, UI overlay, full edit), to pehle `.claude/skills/short-form-remotion/SKILL.md` follow karo. Wo Nikhil ka poora editing brief hai, aur saare lessons se juda hua hai.
5. Notes Hinglish me likho, Nikhil ki tarah. Technical terms (blur, opacity, drop shadow) English me hi rehne do.
