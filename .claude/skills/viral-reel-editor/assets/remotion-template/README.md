# Remotion template (from reel 01 "3 mistakes")

Copy this folder into a new project, `npm install`, put the cut footage at `public/footage.mp4`, and replace the reel-specific parts.

| File | Generic or reel-specific |
|------|--------------------------|
| `src/theme.ts` | Generic. Local fonts, colors (change `accent` to the footage's dominant color), `FACE` point (measure on a frame), `SPLIT` |
| `src/lib.ts` | Generic. Easing, `prog`, `popScale`, `wordIn`, word access |
| `src/SpeakerLayer.tsx` | Generic. Half-screen shift, zoom punch-in, UI dim + blur (reads `SCENES` keys `half1..3`, `zoom`, UI windows) |
| `src/Captions.tsx` | Generic. Setup → payoff → tail, word-synced |
| `src/scenes/Paper.tsx` | Generic. Paper BG + `SceneFrame` (half/full enter/exit/push-in) |
| `src/OnScreenUI.tsx` | Mostly generic. Stepper / slider / name tag — edit the `STEPPERS`, `SLIDERS` specs and the name tag text |
| `src/timeline.ts` | **Reel-specific.** `SCENES` windows + `CAPTIONS` groups (word indices, script words, text fixes) |
| `src/scenes/Scenes.tsx` | **Reel-specific.** The half/full scenes. Keep the helpers (`Gfx`, `SW`, `SS`, `GhostCard`, `card`), rewrite the scene components |
| `src/Sound.tsx` | Cue lists are reel-specific; the `Track` / `SoundDesign` mechanics are generic |
| `src/Reel.tsx`, `src/Root.tsx`, `src/index.ts` | Generic (update the scene list in `Reel.tsx`) |
| `src/data/words.json` | Replace with the new transcript (`transcribe.py --merge` on the cut footage) |
| `public/fonts`, `public/sfx` | Generic (sfx regenerated by `scripts/sfx.py`) |
| `public/graphics` | Add this reel's PNG cutouts |
